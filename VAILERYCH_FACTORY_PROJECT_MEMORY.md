# VAIЛЕРЫЧ Factory — рабочая память проекта

## Цель
Автоматизированное производство русскоязычных образовательных Shorts/Reels с персонажем VAIЛЕРЫЧ. Темы объясняются простым языком через абсурдный дворовый юмор.

## Художественное направление
- Постоянный персонаж: ретро-пацан 2007 года, чёрная кепка, тёмный спортивный костюм с белыми лампасами, светлые потёртые кроссовки, семечки.
- Лицо характерное и асимметричное: тяжёлые брови, прищур, грубоватые черты, наглая ухмылка.
- Визуал: авторская выразительная 2D-иллюстрация с живой линией, неодинаковой толщиной контура, объёмной светотенью, фактурой кожи/ткани/окружения и тёплой палитрой.
- Запрещённый визуальный результат: стерильная плоская векторная геометрия, одинаково толстые контуры, симметричная маскотная морда, борода из точек, примитивные прямоугольные декорации.
- Персонаж должен взаимодействовать с объясняемым явлением, двигаться и менять выражения. Не просто говорящая голова.
- Все сцены генерируются программно. Не использовать сторонние видео/картинки и ImageGen.

## Техническая основа
- Репозиторий: https://github.com/viral-media-lab/vailerych-factory
- Remotion + React + TypeScript + SVG; вертикальный формат 1080×1920, 30 fps.
- GitHub Actions выполняет typecheck и MP4 render, сохраняет артефакт.
- Instagram autopublish — поздний этап, после готовности контентного конвейера и настройки Meta API.

## Утверждённый пилот
Тема: «Почему ты не можешь пощекотать сам себя?» Целевой хронометраж около 40–45 секунд.
Сценарий: провокационный хук; аналогия с корешем; объяснение предсказания мозгом сенсорных последствий собственных движений; мини-Валерыч-диспетчер в мозгу; неожиданная рука и паника; финальный панч.

## Статус на 2026-11-18
- Предыдущая версия персонажа была простым SVG из геометрических фигур и отклонена пользователем.
- Версия 2: переработаны контуры лица и тела, асимметрия, объёмная кожа/ткань, градиенты, фактура, кепка и stubble; добавлены мимические состояния и движение.
- Сборка v2 остановилась на TypeScript из-за экранированных обратных кавычек в двух TSX-файлах; исправление синтаксиса выполняется отдельно. Текущая композиция — визуальный тестовый preview, не финальный ролик. Перед продолжением необходимо проверить рендер по кадрам.
- Не объявлять художественное качество утверждённым до визуальной проверки MP4.
