# VAIЛЕРЫЧ Factory

Программный конвейер для производства русскоязычных образовательных Shorts/Reels с постоянным 2D-персонажем VAIЛЕРЫЧ.

## Текущий статус
- Remotion + React + SVG.
- Вертикальная тестовая композиция Pilot01: 1080×1920, 30 fps, 5 секунд.
- Персонаж разделён на SVG-группы для последующего риггинга.
- Это технический прототип, не готовый пилот.

## Запуск локально
```bash
npm install
npm run start
```

Рендер:
```bash
npm run render
```
